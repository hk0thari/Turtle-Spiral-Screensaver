This is a screensaver made using turtle! Originally made as a school project in 2023
The screensaver will run in full-screen with black background and white spirals (can be configured!)
There are two ways to use it:

Method 1: Using PyInstaller
1. Install PyInstaller: pip install pyinstaller
2. Create executable: pyinstaller --onefile --windowed spiral_screensaver.py
3. Rename the .exe file to .scr: move dist\spiral_screensaver.exe spiral_screensaver.scr
4. Copy the .scr file to C:\Windows\System32\
5. Right-click desktop -> Properties -> Screen Saver -> Select "Spiral Screensaver"
6. The screen saver can be configured from the same place

Method 2: Quick test
1. Just run: python spiral_screensaver.py
2. Press Escape or click to exit
